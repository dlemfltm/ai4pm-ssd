# 1조 SSD · 예상손익 LLM Wiki

> 더미 예상손익 자료를 **AI와 팀원이 다시 쓸 수 있는 팀 지식**으로 정리한 1주차 결과물.
> AI에게 바로 코딩시키지 않고, 근거 있는 자료를 먼저 갖춘 뒤 그 위에서 일하게 한다.

**제출일 2026-08-15** · 이현옥 · 윤호석 · 이혜림

## 결과 요약

| 항목 | 결과 |
|---|---|
| 확인 자료 | **8건** (공식·승인 3건 이상) — `vault/wiki/자료대장.md` |
| 지식 문서 | **8건** — 전부 `reviewed` |
| 내린 결정 | **3건** — `vault/wiki/decisions/` |
| 검사기(wiki_lint) | **오류 0 · 경고 0 PASS** |
| 교차 검토 | 완료 (Q-A·B·C 전부 O) |

## 우리가 내린 결정

- **실적(actual)은 항상 0보다 크다** → 빈값·0·음수는 데이터 오류로 판정하고 계산에서 제외
- **차이 임계값 = 달성율 ±10%** → 범위 밖 항목만 사람이 원인 규명
- **색상은 유리/불리** → 수익 +10%↑ 파랑 / −10%↓ 빨강, 비용 −10%↓ 파랑(절감) / +10%↑ 빨강(초과)

## 폴더

```
vault/
  raw/    확인한 원문 6건 (수정 금지)
  wiki/   지식 — index · log · 자료대장 · sources 6 · concepts 8 · decisions 3 · projects 1
week1-제출/
  01-시작안내/    프로젝트 설명 · AI 작업규칙
  02-질문과-출처/  질문과답변 · 참고도서 · 확인한-자료
  03-결과와-제출/  제출요약 · 핵심질문답변 · 교차검토 · 3분 설명자료 · 검사 로그
scripts/wiki_lint.py  링크·속성·출처·고립 문서 자동 검증
```

## 읽는 순서

1. `week1-제출/01-시작안내/프로젝트설명.md` — 이 프로젝트가 무엇인지
2. `week1-제출/02-질문과-출처/질문과답변.md` — 개발 질문 5개
3. `vault/wiki/자료대장.md` — 어떤 자료에 근거했나
4. `vault/wiki/index.md` — 정리한 지식 목차
5. `week1-제출/03-결과와-제출/제출요약.md` — 결론과 배운 점

## 검증 방법

```
python scripts/wiki_lint.py vault
```

끊어진 링크·누락 속성·출처 없는 문서·고립 문서를 점검한다. 실행 로그는 `week1-제출/03-결과와-제출/wiki-lint-log.md`.

# (원본) Team 01 · Forecast P&L Starter

아래는 과제 시작 시 제공된 스타터 안내다. 규칙 참고용으로 보존한다.

더미 프로젝트 월별 자료에서 계획·실적·차이와 확인 필요 항목을 만드는 시작 폴더입니다.

## 5단계 시작

1. `CLAUDE.md`와 `.claude/` 역할을 읽습니다.
2. `samples/input/project_pnl_sample.csv`와 기대 결과를 비교합니다.
3. Claude Code에 `/forecast-pnl` 또는 자연어로 입력 검사 계획을 요청합니다.
4. 결과는 `outputs/forecast-pnl-report.md`에 저장합니다.
5. `tests/eval-cases.md` 10개를 실행하고 판정을 기록합니다.

## Bronze

정상 Sample에서 법인·월별 계획·실적·차이 표를 만듭니다.

## 사람 확인

PM·재무 담당자가 가정, 합계, 차이 기준, 승인 상태를 확인합니다.

## 금지

실제 손익, SAP 연결, 계정정보, 자동 승인, 투자 판단을 사용하지 않습니다.
