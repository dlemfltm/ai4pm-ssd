# 자료 제목

## 원문

- 원문 파일: [[raw/SRC-YYYYMMDD-001-file-name]]
- 확인일: YYYY-MM-DD
- 확인자: 확인 필요
- 자료 성격: 공식문서 / 인터뷰 / 회의록 / 가이드 / 기타

## 이 자료로 답할 질문

- 확인하려는 질문을 한 문장으로 작성한다.

## 확인된 내용

- 확인된 사실을 적는다. 각 항목 끝에 원문의 절·페이지·문단을 표시한다.

## 프로젝트 적용 후보

- 원문의 사실이 아니라 팀이 검토할 적용 아이디어를 적는다.

## 충돌 또는 확인 필요

- 다른 자료와 다른 내용, 누락된 내용, 추가로 물어볼 내용을 적는다.
