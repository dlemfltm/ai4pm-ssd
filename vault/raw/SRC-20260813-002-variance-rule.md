# 원문 · 차이/차이율 계산 규칙 (더미)

- 성격: 내부 회계 규칙 메모 (더미 자료)
- 수집일: 2026-08-13
- 비고: 학습용 더미 규칙이다.

## 차이 계산

- 차이(variance) = 실적(actual) − 계획(plan)
- 부호는 유지한다. 음수 조정도 그대로 표시한다.

## 차이율 계산

- 차이율(%) = (차이 ÷ 계획) × 100
- **계획(plan)이 0이면 차이율을 계산하지 않고 "확인 필요"로 표시한다.**

## 해석 주의 (문단 3)

- revenue: 차이 양수 = 계획 초과 달성
- cost / expense: 차이 양수 = 예산 초과(주의)
- 최종 해석과 승인은 사람이 확인한다.
