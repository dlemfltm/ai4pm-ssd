# 데이터 무결성 원칙

## 한 줄 정의

빈 값을 추측하지 않고, 원본을 수정하지 않으며, 모든 값은 원문으로 추적한다.

## 확인된 내용

- 빈 값을 0으로 추측하지 않는다. (근거: [[wiki/sources/SRC-20260813-001-pnl-input-spec]])
- 입력 원본을 수정하지 않는다. (근거: [[wiki/sources/SRC-20260813-001-pnl-input-spec]])
- 원문은 `raw/`에 그대로 보관하고 가공본만 `wiki/`에 만든다. → [[wiki/concepts/LLM위키3층구조]]

## 사용처

- 입력 검사·계산·보고서 작성 전 과정의 공통 원칙. 누락 값은 채우지 않고 "누락"으로 표시.

## 예외와 주의점

- 누락은 숨기지 않고 행 번호와 함께 드러낸다.
