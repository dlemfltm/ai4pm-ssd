# 예상손익 보고서

## 목표

- PM·재무 담당자가 월별 계획 대비 실적을 빠르게 확인하기 위해, 더미 CSV 1개에서 계획·실적·차이·차이율 보고서 1개를 만든다.

## 확인된 입력과 규칙

- 입력은 `month, company, project_id, category, plan, actual` 6개 열이다. (근거: [[wiki/sources/SRC-20260813-001-pnl-input-spec#확인된 내용]])
- 차이 = 실적 − 계획, 차이율 = 차이 ÷ 계획 × 100. (근거: [[wiki/sources/SRC-20260813-002-variance-rule#확인된 내용]])
- 계획이 0이면 차이율을 계산하지 않고 확인 필요로 표시한다. (근거: [[wiki/sources/SRC-20260813-002-variance-rule#확인된 내용]])

## AI가 맡을 일

- 입력 검사(input-checker), 차이·차이율 계산(pnl-analyst), 보고서 초안 작성, Reviewer 자체 검토(finance-reviewer).

## 사람이 확인할 일

- 합계와 부호, 차이가 큰 항목의 실제 원인, 가정·누락값, 최종 승인 상태.

## 완료 결과

- `outputs/forecast-pnl-report.md` 1개 + 실행 Test Log + 사람 확인 목록.

## 확인 필요

- actual 빈 값 처리 방식, 차이 임계값 기준이 아직 정해지지 않았다.
