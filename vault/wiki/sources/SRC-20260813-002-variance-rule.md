# 차이·차이율 계산 규칙

## 원문

- 원문 파일: [[raw/SRC-20260813-002-variance-rule]]
- 확인일: 2026-08-13
- 확인자: 이혜림
- 자료 성격: 회계 규칙 메모 (더미)

## 이 자료로 답할 질문

- 계획과 실적으로 차이·차이율을 어떻게 계산하고, 계획이 0일 때는 어떻게 처리하는가?

## 확인된 내용

- 차이 = 실적 − 계획, 부호는 유지한다. (원문 "차이 계산")
- 차이율(%) = (차이 ÷ 계획) × 100. (원문 "차이율 계산")
- 계획이 0이면 차이율을 계산하지 않고 "확인 필요"로 표시한다. (원문 "차이율 계산")
- cost/expense는 차이 양수가 예산 초과를 뜻한다. (원문 문단 3)

## 프로젝트 적용 후보

- pnl-analyst가 plan=0 행을 만나면 차이율 대신 "확인 필요"를 출력하도록 한다.

## 충돌 또는 확인 필요

- 차이가 큰 항목의 "큰"의 기준(임계값)은 원문에 없음 → 담당자 확인 필요.
