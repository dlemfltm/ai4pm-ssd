# 결정: 실적(actual) 빈값·0 처리

## 결정

- **실적(actual)은 조직이 활동하는 한 항상 0보다 크다**는 업무 전제를 채택한다.
- 따라서 `actual`이 **빈값 · 0 · 음수**인 행은 **데이터 오류**로 판정한다.
- 해당 행은 **차이·차이율을 계산하지 않고**, 입력 이슈 목록에 **행 번호와 사유**를 표시한다.

## 근거

- 입력 명세상 `actual`은 정수이며, **빈 값을 0으로 추측하지 않는다**. (근거: [[wiki/sources/SRC-20260813-001-pnl-input-spec]])
- 원칙 정리: [[wiki/concepts/데이터무결성]]

## 사용처

- `input-checker`가 `actual ≤ 0` 또는 빈값인 행을 오류로 표시하고, `pnl-analyst`는 그 행을 계산에서 제외한다.

## 확인 필요 / 한계

- 신규 프로젝트 착수월 등 **실적이 정상적으로 0인 예외**가 있으면 별도 처리 규칙이 필요하다. 현재는 오류로 본다.
