# 결정: AI/사람 역할 경계

## 결정

- **AI**: 입력 검사 · 차이 계산 · 보고서 초안(가공)까지 수행한다.
- **사람**: 최종 보고서 승인 · 차이 원인 판정 · 임계값 확정 · 민감정보/실제 손익 처리를 맡는다.

## 근거

- 원저 원칙: 사람은 원문 선별·분석 지시·질문을, LLM은 나머지(요약·연결·정리)를 맡는다. (근거: [[wiki/sources/SRC-20260814-104-karpathy-llm-wiki]])
- 개념 정리: [[wiki/concepts/근거추적검증]]

## 사용처

- 워크플로우에서 AI 산출물과 사람 승인 단계를 나누는 기준. `needs-review → reviewed` 승격도 이 경계를 따른다.

## 확인 필요 / 한계

- 자동 승인을 코드로 막는 **기술적 게이트는 없다** → 사람이 반드시 최종 확인한다. (참조: `week1-제출/01-시작안내/프로젝트설명.md`의 "사람 승인 게이트")
